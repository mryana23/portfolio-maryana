🚀 My Personal Portfolio
Welcome to the repository of my personal portfolio! This project showcases my skills, projects, and journey as a Web Developer. It's built with a focus on clean code, performance, and modern UI/UX principles.

🌐 Live Demo
You can view the live site here: portfolio-maryana.vercel.app

🛠️ Tech Stack
This portfolio is built using modern web technologies:
Framework: React.js + Vite (for ultra-fast development)
Styling: Tailwind CSS
Deployment: Vercel

✨ Key Features
Fully Responsive: Optimized for mobile, tablet, and desktop screens.
Modern UI/UX: Clean aesthetic with smooth transitions.
Optimized Performance: Fast loading times and SEO friendly.
Contact Integration: Easy way for recruiters to reach out.

📁 Project Structure
Brief overview of how the code is organized:
/src/components: Reusable UI components.
/src/assets: Images, icons, and static files.
/src/data: Content data (to make it easy to update projects/skills).

🚀 Getting Started
If you want to run this project locally:
1. Clone the repo:
git clone https://github.com/mryana23/portfolio-maryana
2. Install dependencies:
npm install
3. Run development server:
npm run dev
